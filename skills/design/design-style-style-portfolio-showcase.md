# 디자인 스타일: Portfolio Showcase (포트폴리오·쇼케이스) · 웜

**ID:** `SKL-STYLE-PORTFOLIO-SHOWCASE`  
**범위(Scope):** Design Style  
**우선순위:** High  
**적용 조건:** 포트폴리오, 작품 갤러리, 에이전시 소개, 사진·디자인·건축 쇼케이스, 브랜드 룩북, 크리에이터 소개 페이지에 어울리는 비주얼 중심 스타일. 이미지가 주인공이고 텍스트는 최소한으로, 감각적 인상을 남겨야 하는 화면에 적용한다.

---

## 지시사항 (Instructions)

1. 이미지 원본 비율을 유지하고 UI 장식이 작품과 경쟁하지 않게 한다
2. 타이포그래피는 크기 대비를 극단적으로 써서 위계를 만든다
3. 그리드는 여백을 충분히 두고 한 화면에 6개 이하 작품만 보여준다
4. 이미지에는 지연 로딩과 비율 자리 표시자를 반드시 적용한다

# Portfolio Showcase — 포트폴리오·쇼케이스 스타일

작품이 말하게 하라. UI는 화이트 큐브 갤러리 — 벽은 비어 있고 조명은 작품만 비춘다. 타이포는 크게 쓰거나 아예 작게, 중간은 없다.

## 1. Colors

| 역할 | 값 | 용도 |
|---|---|---|
| Canvas | `#FFFFFF` | 기본 배경 (또는 `#0A0A0A` 다크 택1 — 혼용 금지) |
| Ink | `#0A0A0A` | 텍스트 (다크 시 `#F5F5F5`) |
| Muted | `#737373` | 캡션·메타 |
| Line | `#E5E5E5` | 미세 구분선 |
| Accent | 없음 | 포인트 컬러는 작품이 담당 — UI 무채색 유지 |

## 2. Typography

- 제목: 브랜드 세리프 또는 기하학 산세리프 48~96px/300~400 — 크고 가볍게. `letter-spacing: -0.02em`.
- 본문·소개: 15px/1.8, 최대 두 문단.
- 캡션·메타(연도·클라이언트·역할): 12px/400 Muted, `letter-spacing: 0.05em` 대문자(영문일 때).
- 내비게이션: 13px, 최소 항목(Work · About · Contact).

## 3. Spacing & Layout

- 여백이 레이아웃이다: 섹션 간 120px 이상, 콘텐츠 최대폭 1280px.
- 그리드: 2컬럼 비대칭(60/40) 또는 마소니(masonry). 균일 3컬럼 썸네일 나열은 밋밋함 — 크기 리듬을 준다.
- 히어로: 풀블리드 대표작 1점 + 이름/한 줄 소개만.
- 작품 상세: 상단 풀폭 키 이미지 → 개요(역할·기간·도구) 2컬럼 → 본문 이미지 세로 나열(간격 24px) → 다음 작품 링크.

## 4. Components

- 썸네일: radius 0 또는 2px — 갤러리는 각지게. hover 시 이미지 scale 1.03 + 제목/연도 오버레이 페이드 인.
- 이미지: `aspect-ratio` 자리 표시자(회색 `#F5F5F5`) + lazy loading + 고해상도 srcset.
- 프로젝트 메타 블록: 레이블(Muted 12px) + 값 목록. "Role — Art Direction" 형식.
- 연락 섹션: 큰 타이포 이메일 링크 하나면 충분. 폼 지양.
- 커서: 데스크톱에서 작품 hover 시 "View" 커스텀 커서 허용 (텍스트 가독 방해 금지).

## 5. Motion

- 스크롤 등장: opacity 0→1 + translateY 24px, 500ms ease-out, 1회만.
- 페이지 전환: 300ms 페이드. 과한 커튼·와이프 전환 금지.
- hover scale은 1.03 이하 — 이미지 왜곡 인상 방지.
- `prefers-reduced-motion` 시 등장 애니메이션 전부 제거.

## 6. Accessibility

- 모든 작품 이미지에 구체적 대체텍스트("2024 ○○ 브랜드 패키지 디자인, 흰 배경의 보틀 3종").
- hover에만 의존하는 정보 금지 — 제목·연도는 모바일에서 상시 노출.
- 무채색이어도 텍스트 대비 4.5:1 유지 (Muted #737373는 흰 배경 4.7:1).
- 키보드 포커스 시 hover와 동일한 오버레이 표시.

## 7. Voice & Content

- 짧고 확신 있게. 수식어보다 사실: "패키지 리뉴얼로 재구매율 23% 상승."
- 1인칭 소개는 두 문장 이내. 겸손 과잉("부족하지만…") 금지.
- 캡션 형식 통일: 프로젝트명 · 연도 · 역할.

## 8. Do NOT

- ❌ 이미지 위 반투명 그라데이션 상시 오버레이 (작품 훼손)
- ❌ 워터마크·과한 로고 반복
- ❌ 라이트/다크 혼용 (한 톤으로 통일)
- ❌ 캐러셀 자동 재생 (사용자가 넘긴다)
- ❌ 스톡 이미지로 채운 가짜 포트폴리오 항목

## 성향: 웜·수공예

위 스타일을 웜 성향으로 적용한다 — 따뜻한 크래프트지 위 손맛.
- 웜 아이보리 바탕(#FBF6EF), 잉크도 웜 브라운 블랙(#33291F).
- 포인트 색은 유지하되 채도를 한 단계 낮춰 바탕과 어울리게.
- 세리프 제목 허용, 인용·손글씨 느낌 보조 서체 1곳 허용.
- radius 10~14px, 그림자 대신 종이 겹침 느낌의 옅은 보더.
- 사진은 따뜻한 톤 보정을 전제로 여백과 함께 배치.
